# docs

**Development-cycle documentation**: whatever comes up while building the app and while it stays alive.

Things that belong here:

- Agent guidelines
- Documentation for features already built
- Architecture decisions, environment setup, code conventions
- Runbooks and operational notes

**What does NOT belong here:** the product and requirements definition. That lives in [`../requirements/`](../requirements/) and is kept separate on purpose, so this folder doesn't fill up with product decision-making.

| How it's stored | [`../requirements/DATA-MODEL.md`](../requirements/DATA-MODEL.md) |
| Why it was decided that way | [`../requirements/DISCOVERY.md`](../requirements/DISCOVERY.md) |
| The numbered decisions | `SRS.md` §4 |
